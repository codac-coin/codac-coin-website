# About CODAC-COIN

**CODAC-COIN (Coin of Destiny & Change)** is a blockchain-enabled digital technology ecosystem and account platform currently under development.

The project is being designed to support digital engagement, commerce, merchant services, channel participation, trading verification, account security, organizational participation, and other technology-enabled services through an integrated CODAC Portal.

The public website currently provides project information only. Live public financial services and public fund collection are not conducted through this website.
